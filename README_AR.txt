POLICE AIM PRO - الإصدار الأول

محتويات المشروع:
- main.py: تطبيق إعدادات بسيط بثلاثة منزلقات وحفظ محلي.
- buildozer.spec: إعدادات بناء تطبيق أندرويد.
- .github/workflows/build-apk.yml: بناء APK عبر GitHub Actions.

طريقة البناء:
1) أنشئ مستودع GitHub جديداً باسم police-aim-pro.
2) ارفع محتويات هذا المجلد إلى جذر المستودع.
3) افتح Actions ثم اختر Build POLICE AIM PRO APK ثم Run workflow.
4) بعد نجاح البناء افتح صفحة التشغيل، ثم Artifacts، وحمّل POLICE-AIM-PRO-APK.
5) فك ضغط الملف وثبّت APK على هاتفك.

مهم:
هذا التطبيق مساعد لإعدادات الحساسية فقط. لا يعدّل PUBG Mobile،
ولا يحقن ملفات أو أوامر، ولا ينفذ تصويباً تلقائياً أو No-Recoil.
القيم مجرد نقاط بداية وليست إعدادات مضمونة لكل لاعب أو جهاز.
